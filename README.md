# A/B-тест персонализированного предложения кредитной карты

Учебный pet-project по A/B-тестированию, клиентской аналитике и статистической проверке гипотез.

## Бизнес-задача

Смоделировать маркетинговую кампанию по продвижению кредитной карты и проверить, увеличивает ли персонализированное предложение эффективность кампании по сравнению со стандартным.

## Ограничение проекта

В проекте используется открытый датасет **UCI Bank Marketing** для исходных характеристик клиентов. Он содержит 45 211 наблюдений и относится к исторической кампании португальского банка по продвижению срочных депозитов.

Я **не выдаю исходный `y` за результат моего эксперимента**. Этот A/B-тест и его результаты синтетические: они генерируются программно после случайного распределения клиентов на группы. Это позволяет контролировать постановку эксперимента и честно показать статистический анализ.

Источник: Moro, S., Rita, P., Cortez, P. (2014), UCI Machine Learning Repository, Bank Marketing.
https://doi.org/10.24432/C5K306

## Гипотеза

**H0:** средний доход на одного пользователя одинаков в контрольной и экспериментальной группах.

**H1:** средний доход на одного пользователя различается между группами.

Основная метрика — средний доход на пользователя.

Вторичная метрика — конверсия в оформление продукта.

Для основной метрики используется **двусторонний Welch t-test**, для конверсии — **z-тест разницы двух пропорций**.

## Запуск

1. Скачать `bank-full.csv` с официальной страницы UCI.
2. Положить файл в `data/raw/bank-full.csv`.
3. Установить зависимости:

```bash
pip install -r requirements.txt
```

4. Запустить `notebooks/01_experiment.ipynb`.

## Следующие этапы

1. Подготовка и исследование клиентских данных.
2. Формирование целевой аудитории.
3. Случайное распределение 50/50.
4. Генерация результатов симулированной кампании.
5. Проверка баланса групп.
6. Welch t-test для средней выручки.
7. z-test для конверсии.
8. Доверительные интервалы и оценка абсолютного/относительного эффекта.
9. Анализ эффекта по клиентским сегментам.
10. SQL-витрина результатов.
11. Итоговый дашборд и бизнес-рекомендация.
